- Moulay A. Akhloufi, [Arxiv & PRIME AI Style Template](https://www.overleaf.com/latex/templates/arxiv-and-prime-ai-style-template/qdnhqytdqzsc), distributed as CC BY 4.0 on Overleaf.

- The Overleaf gallery's “Open as Template” route requires a login. The included `PRIMEarxiv.sty` was obtained from a [public copy of Akhloufi's template](https://github.com/josearangos/Speech-separation-in-real-time-using-deep-learning-architectures) and matched a [second public mirror](https://github.com/keanteng/arxiv-latex). The style file is unchanged; `main.tex` uses its arXiv layout with a course running header.

For Overleaf, upload the accompanying ZIP and select `main.tex`; two pdfLaTeX passes resolve references. `submission-details.tex` contains the group status fields and repository URL. `data.tex` and the vector charts come from the package analysis; no separate Python execution is needed in Overleaf.
